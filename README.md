# Full Stack Learning Tracker

A web application to track your progress in full stack development learning journey. Built with HTML, JavaScript, and Tailwind CSS.

## Features

- Track multiple learning paths (Frontend, Backend, Database)
- Add/remove learning resources
- Mark completion status
- Progress visualization
- Data persistence using localStorage
- Responsive design

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Local Storage API
